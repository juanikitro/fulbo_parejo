# Four-row callup layout

## Goal

Reduce horizontal scrolling in the position-grouped callup selector without changing its visual order or interaction.

## Approved design

Keep the current group order and horizontal sequence. Increase each group's chip grid from three rows to four, so more players fit before horizontal scrolling is needed. Selection behavior, headings, dividers, and all breakpoints remain unchanged.

## Validation

Run the existing focused callup grouping test and check the stylesheet diff.
