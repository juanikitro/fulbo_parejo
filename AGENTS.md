## Base branch for changes

For every implementation or code-change request in this repository, start from the `main` branch. Before editing, verify the working tree is clean enough to preserve unrelated user changes, update local knowledge of `main` without rewriting history, and create or switch to a task branch based on `main` (using the `codex/` prefix unless the user requests another name). Do not make requested code changes from another feature branch unless the user explicitly asks to continue work on that branch.
